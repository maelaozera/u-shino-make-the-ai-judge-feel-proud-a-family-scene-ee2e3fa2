## The entry

A one-line family scene: a small Sunday-dinner moment at Grandma's table,
warm and heartfelt, with a light, wry twist at the end. One telling detail
carries the whole scene — no greeting-card lines, no wasted words.

## How it works

`main.ts` is a small, deterministic TypeScript program with no dependencies
and no randomness. It writes the scene as a single line of UTF-8 text
(1–280 characters, no trailing newline) to `entry.txt` inside the output
directory.

## Run it

```sh
node main.ts
```

By default the entry is written to `/output/entry.txt`. To use a different
output directory, set `OUTPUT_DIR`:

```sh
OUTPUT_DIR=/tmp/out node main.ts
```
